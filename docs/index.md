# Lista de Filmes

Bem-vindo à documentação da **Lista de Filmes** - uma plataforma completa para catalogação de filmes e gerenciamento de elenco.

## O que é este projeto?

É uma aplicação full-stack que permite:
- 📽️ Catalogar filmes com título, gênero e classificação
- 🎭 Gerenciar atores e suas relações com filmes
- 📥 Importar automaticamente títulos de uma API externa
- 📚 Acessar documentação interativa da API (Swagger)

## Stack Tecnológico

### Backend
- **Node.js** + **Express** - API REST robusta
- **Supabase** (PostgreSQL gerenciado) - Banco de dados
- **Swagger/OpenAPI** - Documentação interativa

### Frontend  
- **Vue 3** - Framework progressivo
- **Vite** - Build tool e dev server
- **Tailwind CSS** - Estilos

## Recursos Principais

✅ **Gerenciamento de Filmes** - CRUD completo com validação  
✅ **Gerenciamento de Atores** - Cadastro e associação com filmes  
✅ **Importação Automática** - Seed idempotente de dados  
✅ **API Documentada** - Swagger interativo em `/api/docs`  
✅ **Interface Amigável** - Frontend em Vue 3 com Vite
